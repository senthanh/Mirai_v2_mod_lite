# 🎤 LOUD MIC - APO PROCESSOR

**100% Full Volume | No Clipping | APO Quality**

## 📋 Features

✅ **100% FULL VOLUME** - To hết cỡ
✅ **APO Processing** - Normalization + Compression + Soft Clipping
✅ **No Clipping/Distortion** - Chất lượng 100%
✅ **4 Presets**:
   - 🔊 Soft (80%) - Nhẹ nhàng
   - 🔉 Normal (120%) - Bình thường
   - 🔊 LOUD (180%) - To khá
   - ⚡ ULTRA (250%) - MAXIMUM POWER!

## 🎮 Commands

```
/lmic          - Bật/Tắt GUI chính
/lsoft         - Soft Mode (80%)
/lnormal       - Normal Mode (120%)
/lloud         - Loud Mode (180%)
/lultra        - ULTRA Mode (250%) - TO HẾT CỠ!
```

## 🎨 GUI Features

- Giao diện tím đẹp (APO style)
- Master Volume Slider (50-300%)
- 4 button presets
- Real-time status display
- Processing indicator

## 🔧 Audio Processing

**APO-style Processing:**
1. **Normalization** - Giữ chất lượng tối đa
2. **Dynamic Compression** - Ngăn chặn peak distortion
3. **Soft Clipping** - Không bị méo tiếng
4. **Real-time Processing** - 10ms update cycle

## 📦 Installation

1. Copy `LoudMic.lua` vào folder `monetloader`
2. Gọi trong main script
3. Sử dụng `/lmic` để mở GUI

## ⚠️ Notes

- ULTRA mode (250%) - Sử dụng khi cần âm lượng cực đại
- Soft Clipping ngăn chặn distortion ở mức âm lượng cao
- Compression algorithm tự động điều chỉnh dựa trên mức volume
